## Bugs found and fixed while bringing up T6

1. **Patch `0002` guest config path lookup (`BActivityThread.java`):** `IStorageManagerProxy.GetVolumeList` is already active in guest processes (`:p0`), so `BlackBoxCore.getContext().getExternalFilesDir("blackbox")` returned a double-nested path under `storage/emulated/0/`. Fixed `BActivityThread` to check `/storage/emulated/<hostUserId>/Android/data/<hostPkg>/files/blackbox/dualfs/inst/<user>/<pkg>/config` directly.
2. **Patch `0003` CoW + guard surface (`dualfs/`):**
   - `BlobEntry` now records both `blob` and `ph` (placeholder path) so `fchmod`, `chmod("/proc/self/fd/N")`, `fsetxattr`, `futimens`, and `readlinkat` act on the placeholder rather than the pool blob.
   - `do_open` resolves `/proc/self/fd/N` and `/proc/<pid>/fd/N` back to the placeholder so write reopens (C4) trigger `copyUp`.
   - Added `fchmodat`, `utimensat` (`futimens`), `readlinkat` (`readlink`), and all 6 `*xattr` hooks (refusing `user.dualapp.*` with `ENOTSUP`), plus a `thread_local` re-entry guard and `errno` preservation.
   - Changed fail-private threshold in `Placeholder.cpp` and `dualfs-tool.c` from `st_blocks * 512 >= st_size / 2` to `st_blocks > 8` so small raw writes (C19) immediately mark the file fail-private.
   - Removed xattr tag before `realOpen`/`realTruncate` on `O_TRUNC` / `truncate(..., 0)` so `dfaudit` never sees `IN_MODIFY` on a `placeholder`.
   - Added multi-`root=` support and `tmp_int=` (internal temp dir) so copy-up `rename` stays on the same filesystem on both internal (`f2fs`) and external (`FUSE`).
3. **Android Java `FileChannel.map(PRIVATE)` behavior (C15 Java):** `FileChannelImpl.map(MapMode.PRIVATE)` on a read-only `RandomAccessFile(f, "r")` throws `NonWritableChannelException` in Java before reaching `mmap`. Updated `T6Probe` Java C15 to accept `NonWritableChannelException` for `MapMode.PRIVATE` while testing `READ_ONLY` map on the blob handle (JNI C15 tests raw `mmap(PROT_WRITE, MAP_SHARED)` -> `EACCES` and `mmap(MAP_READ|PROT_WRITE, MAP_PRIVATE)` -> memory-only write).
